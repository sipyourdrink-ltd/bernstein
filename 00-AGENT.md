## Golden Commands

| Command | Purpose |
|---|---|
| `uv sync` | Install dependencies and lock environment |
| `uv run python scripts/run_tests.py <test-path>` | Run isolated unit tests |
| `uv run ruff check .` | Lint codebase |
| `uv run ruff format .` | Format codebase |
| `uv run mypy src` | Typecheck core package |
| `uv run bernstein agents-md verify` | Verify AGENTS.md mirrors are in sync |
| `python3 scripts/check_docs_drift.py` | Verify documentation has not drifted |

## Rules for Agents Editing this Repo

1. **Do not hand-edit `AGENTS.md`, `CLAUDE.md`, or the 15 mirror files**: They are generated by `bernstein agents-md sync`. Curated overlays live in `.sdd/agents-md/`.
2. **Never break existing MkDocs navigation**: Paths declared in `mkdocs.yml` must resolve cleanly.
3. **Strict verification**: Run `agentdocs verify --mode strict` whenever changing files referenced in `docs/agent/`.
4. **Governance invariants**: Bernstein is the open-source governance layer for AI agents; preserve deterministic scheduling, offline receipt verification, and air-gap compatibility.
