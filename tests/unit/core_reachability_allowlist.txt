# Modules under src/bernstein/core that the static reachability trace in
# tests/unit/test_core_reachability.py cannot reach, one per line, as
# `dotted.module: reason`.
#
# A line is a claim, and the claim is one of two things:
#
#   * the module IS reached, by a mechanism the trace cannot see - a dotted
#     string resolved at call time, an entry point, the lazy-alias finder. The
#     reason names that mechanism.
#   * the module is unreachable and its wire-or-delete decision is still open -
#     a #4526 candidate whose package audit has not run, or a module that landed
#     under core/ while #4526 was open. The reason says which, and the decision
#     replaces the line with a wiring commit or a deletion.
#
# The baseline is the tree at the commit this guard turns on, not the commit the
# file was first written. Modules kept landing under core/ while this change sat
# in review, and each one gets a line because the line is a true statement about
# the tree the guard ships against - recording them as #4526 candidates instead
# would put a false provenance in a file whose only value is that its lines are
# true.
#
# From that commit the list may only SHRINK. Adding a module here to make a red
# build green is not an allowlist entry, it is a suppression: a new module that
# nothing imports is a defect at the pull request that adds it.
#
# Sorted; keep it that way so a diff reads as one line added or removed.
