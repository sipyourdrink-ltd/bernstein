# Disclaimer

## Volunteers work on their own behalf

A volunteer runs tasks on equipment they control, using credentials they
provided themselves. No volunteer acts as an agent of any project, and no
project directs how a volunteer chooses to donate time or compute. A
volunteer's work is the volunteer's alone unless a project explicitly
accepts it.

## Projects own their decisions

A project decides what to merge, what to reject, and what standard a
submission must meet. The volunteer program only delivers a signed
receipt bundle and its gate results; the project applies its own bar.

## The software is provided as-is

This program ships under Apache-2.0. The license does not grant a warranty,
and the license's limitation of liability applies. Review the LICENSE file
for the full text.

## No central service operates this program

Volunteer tasks run on donor hardware in donor sandboxes. There is no
Bernstein-operated service that executes tasks, stores submissions, or
mediates between donors and projects. A `bernstein volunteer hub` is run
only by whoever starts it, against a store they control.
