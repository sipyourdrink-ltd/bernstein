# Maintainer quote: template

Copy, fill the angle brackets, delete what does not apply. Keep it short:
the quote itself is two to four sentences, and the whole message fits on a
phone screen.

---

Subject: Bernstein quote for <their project / announcement>

Hi <name>,

Thanks for asking. Here is a quote you can use for <the announcement /
the release note / the integration page>:

> "<Two to four factual sentences in the maintainer's voice. What the two
> projects do together, one concrete detail (a command, an interface, a
> spec section), and why it matters to a user. No superlatives, no market
> claims.>"
>
> Alex Chernysh, maintainer, Bernstein (https://bernstein.run)

Feel free to edit or cut this for length. If the final wording materially
changes the meaning, please send me the final version before publication.

<Optional, one line: a link to the issue or pull request where the
integration actually happened, so readers can verify it.>

Alex
