# External outreach, the light version

This folder is for the moments when Bernstein genuinely crosses paths with
another project or organisation and somebody needs a sentence from the
maintainer: a quote for their release announcement, a cross-project
reference, a technical acknowledgement. Nothing here is a campaign. It is a
way to answer such a request in an hour instead of a week, and to keep the
wording afterwards so nobody has to reconstruct it.

The pipeline, in full:

```
real relationship -> opportunity -> short factual draft -> maintainer review -> external use -> LOG.md
```

## How a request is handled

1. **It starts from a real relationship.** A project we integrate with, a
   standard we implement, a maintainer who already talked to us in an issue.
   Cold "would you endorse us" mail is not an opportunity; it is mail.
2. **Draft from `quote-request.md`.** Two to four sentences, factual, in the
   maintainer's own words. The template carries the permission line that
   every quote we send out has carried so far: they may edit or cut it for
   length, and if the final wording changes the meaning they send it back
   before publication.
3. **Maintainer reads it.** Nothing leaves without that. The maintainer title
   in the signature is the one in `MAINTAINERS.md`, not a job title invented
   for the occasion.
4. **It goes out**, by whatever channel the relationship already uses.
5. **The final wording is recorded in `LOG.md`** once it is public, with the
   link. That is the whole archive.

## What this is not

Not a press kit, not a partner programme, not a place to keep contacts or
private correspondence (those stay out of the repository). Sponsorship and
advertising are a separate conversation with the maintainer; the pinned
recognition issue says how to start it.
