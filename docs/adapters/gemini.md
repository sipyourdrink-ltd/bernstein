# `gemini` adapter

The `gemini` adapter is dual-binary aware. The upstream CLI is changing
binary names ahead of a 2026-06-18 deprecation: see
[`antigravity.md`](antigravity.md) for install paths, the discovery
cascade, and the operator override.

The hosted backend behind this lane was discontinued for non-enterprise
users in June 2026; the `gemini` adapter remains supported for
enterprise licenses and paid API-key operators. Consumer-path operators
(free / AI Pro / Ultra) should use the separate `agy` adapter for the
successor Antigravity CLI: see [`agy.md`](agy.md) for the lane split.
