# v3.24.0

This release adds cooperative task cancellation, a resumable journal stream for the terminal UI, and local merge-backs that can skip pushing to the remote (#6742, #6846, #5982). Graduation diagnostics can compare stored counters with sealed journal observations, and audit verification now checks published hash tiles (#6859, #6548).

## Stop work before releasing its claim

Cooperative cancellation retains the claim until the orchestrator observes termination; immediate cancellation remains the default (#6742). Without a running orchestrator, requests stay pending; living in-process threads retain their claims, and execution tracking remains in memory (#6742).

## Follow a run's journal in the terminal

`/events/thread` streams journal indices with resume across server restarts (#6846). Resume depends on retained rows, and run changes reset the cursor (#6846). The consumer buffers split frames and advances its cursor only for complete frames (#6842); unavailable journals use polling, and invalid URLs stop consumption (#6851).

SSE slots stay occupied until streams close (#6869). `/api/v1` aliases share canonical request limits and SSE caps (#6871).

## Keep merge-backs local

`BERNSTEIN_LOCAL_ONLY=1` skips merge-back pushes and pending-push retries, preserving the queue; salvage and evolution pushes can still reach the remote (#5982).

## Compare graduation counters with sealed observations

Graduation diagnostics compare counters with sealed journal observations, refusing damaged evidence; stage-metrics parity remains unestablished and promotion decisions unchanged (#6859). Unknown events and unsupported metrics remain visible (#6859).

## Verify the evidence that was written

`bernstein audit verify` checks published hash tiles against authenticated segments and remains read-only (#6548). Tiles beside damaged segments or without matching segments are not judged (#6548). Failed rollbacks retain receipts naming restored files; receipt-storage failures report both errors (#6857). Injected skill bytes match their audit digest across platforms (#6636).
