# v4.0.1

A patch release on top of v4.0.0. It fixes packaged `bernstein demo` execution from wheels, adds copy-pasteable offline receipt verification hints, resolves fractional-weight stalls in `FairScheduler`, and ships bug fixes across CLI diagnostics, metrics, and release gating. There are no breaking changes and no configuration migration is required.

## First-run demo and offline receipt verification

`bernstein demo` and `bernstein demo --flask-todo` now ship their fixture templates inside the wheel, initialize a clean Git repository for `--flask-todo`, and pass all batched task titles through `CachingAdapter` so multi-task mock sessions complete every assigned fix. At the end of a run, `bernstein demo` prints unwrapped `openssl`, `bernstein verify run`, and `bernstein verify receipt` commands bound to the top-level orchestration journal through `contained_run_journal`, and `bernstein verify run` shows how to generate an Ed25519 key when none is configured (#8142).

## Scheduling, tasks, and metrics

`FairScheduler.dequeue()` advances credits directly to the next runnable round for positive fractional weights while clamping peer deficits so tiny weights cannot raise `OverflowError` (#8035). Priority aging never demotes a task already at or above `min_priority` (#8083), and skill helpfulness scoring selects the latest completion timestamp rather than file order (#8070). `ErrorBudget` reports zero tasks to exhaustion when already depleted (#8081), remainder formulas in custom metrics return `0.0` on a zero divisor instead of aborting the batch (#8082), repository flow-series loaders reject non-integer counters (#8088), direct inbox reads skip non-object JSON records (#8080), and `StreamTailBuffer` returns an empty tail when `limit=0` (#8079).

## CLI, diagnostics, and replay

`bernstein logs search` applies `--limit` after ordering newest matches across sources (#7987). `bernstein diff` retains the final hunk of each file in folded diffs (#7985) and renders literal brackets in word diffs (#7983). `changelog conventional` history links follow `--until` (#7991), notebook trace diffs record cell-type conversions as replacements (#7993), `config-path` writes plain JSON when colour is forced (#7961), and local `resume` reports dispatch outcomes as JSON (#7850). `GoalDriftReplayAdapter` can record an optional in-process intent score on trajectory events for offline replay (#7099, #8006). Benchmark charts sort rows by UTC instant (#7989), trend scoring matches dotted Python release numbers (#7981), file-health scoring matches whole path components (#7974), repository analysis counts test paths relative to the analyzed root (#8091), and default output styles deduplicate by name (#8090).

## Release pipeline and dependencies

The post-CI dispatcher verifies that the exact tested merge-queue commit landed in `main` history before invoking privileged release jobs (#7082). Dependency `wcmatch` is updated to 11.2 (#8074), and `docs/requirements.txt` transitive pins are refreshed for `mkdocs build --strict` (#6940).
