Artifact-mode completion works on Windows. Its signing identity's Agent Card was written to `.sdd/agents/agent:artifact-completion/`, and `:` is not a legal Windows path component, so every artifact-mode task failed there with `NotADirectoryError`. The card now lives under the SHA-256 of the agent id, the encoding datasource receipt cards already use; the lineage gate matches cards by content, so verification is unchanged. A directory at a task's declared output path now reports "wrote no output" on Windows too, instead of a raw `PermissionError`.
