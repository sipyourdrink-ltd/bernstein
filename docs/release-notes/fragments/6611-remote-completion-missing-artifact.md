A task completed by a registered cluster node that posted no verified artifact now fails with `artifact_missing_remote`, including a code task with no completion signals. Before, the janitor graded the run checkout in its place, so stale bytes at the declared output path, or a file that already satisfied a `path_exists` signal, passed the task with no remote work delivered. The server now records the owning node on the task at claim time as `claimed_by_node` (exposed in `TaskResponse`), so the decision makes no network call and still holds after the worker unregisters. Tasks claimed locally, or claimed before this field existed, are graded as before.
