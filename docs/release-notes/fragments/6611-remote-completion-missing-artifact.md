A task completed by a registered cluster node that posted no verified artifact now fails with `artifact_missing_remote`. Before, the janitor graded the run checkout in its place, so stale bytes at the declared output path, or a file that already satisfied a `path_exists` signal, passed the task with no remote work delivered. Completions with no claim owner, an owner that is not a registered node, or an unreadable cluster API are graded as before.
