## `bernstein bench run` reports into CI: SARIF, a scorecard check run, and a delta against a signed baseline

`bernstein bench run --sarif-out <path>` writes a SARIF 2.1.0 document with one result per failed task, located at the suite's own source; `--baseline <bundle>` prints a scorecard with the pass-rate delta and, with `--repo`/`--head-sha`, publishes it as the `bernstein / bench scorecard` check run. The conclusion is green or red only over a baseline that is signed, from the same suite, and re-verified receipt by receipt; a missing, unsigned, altered, foreign or unverifiable baseline is neutral with the reason in the summary, and `--ci` exits 1 on a regression past `--regression-threshold`. A non-stub signature is checked for presence only until #5856, and the scorecard summary says so; a check run that could not be posted is announced on stderr (#5458).
