SQLite WAL store replaces JSON persistence for the cluster node registry, with import of an existing `nodes.json`. Edge relay (Cloudflare Workers + Durable Objects) handles batch heartbeats and routes by consistent hash ring. Sharding is configured with `cluster.shard_id` and `cluster.shards` in the seed; `GET /cluster/shard-map` reports the topology. Health telemetry fields (`disk_free_mb`, `mem_used_pct`, `mesh_rtt_ms`, `platform`, `health`, `unhealthy_since`) provide granular node status.
