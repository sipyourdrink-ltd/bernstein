SQLite WAL store replaces JSON persistence for cluster scale. Edge relay (Cloudflare Workers + Durable Objects) handles batch heartbeats and routes by shard ID. Sharding configuration (`BERNSTEIN_CLUSTER_SHARD_ID`, `BERNSTEIN_CLUSTER_SHARDS`) distributes node registrations. Health telemetry fields (`disk_free_mb`, `mem_used_pct`, `mesh_rtt_ms`, `platform`, `health`, `unhealthy_since`) provide granular node status.
