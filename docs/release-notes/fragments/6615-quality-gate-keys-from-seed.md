The seed parser now reads every `quality_gates.*` key that `QualityGatesConfig` defines. `mutation_testing`, `dep_audit`, `intent_verification`, `large_file_check`, `migration_reversibility_check`, `test_expansion`, `agent_test_mutation`, `integration_test_gen`, `review_rubric` and their sub-keys were documented and accepted by the schema but never forwarded, so setting them in `bernstein.yaml` left the gate at its default (#6615). Two consequences for existing seeds: this repository's own `bernstein.yaml` sets `large_file_check: true`, which now takes effect, and a `quality_gates.intent_verification:` that is not a mapping, or an integer key such as `timeout_s` given a bare `true`, now raises `SeedError` instead of being ignored.
