## Authenticate install-identity benchmark baselines in scorecards

Python callers can pass trusted public keys to `evaluate_ci_scorecard` so a valid
install-identity baseline can produce a verified success or regression result.
Missing trust, invalid signatures and failed receipt replay remain neutral.
`bench run --baseline` accepts `--trusted-key FINGERPRINT=PATH` to supply
those public keys explicitly. Without a matching key the comparison stays
neutral.
