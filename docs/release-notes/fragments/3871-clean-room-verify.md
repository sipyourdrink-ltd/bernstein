## Volunteer bundles verify against an independent clean-room re-run

`bernstein volunteer verify-bundle <bundle>` re-runs a result bundle's gates in a fresh, detached worktree that shares nothing with the run being checked: the attested base commit, the attested patch applied on top, every gate re-executed and compared against the bundle's attested exit codes and log digests. A bundle whose gates only passed because of a workspace side effect, or whose patch does not apply to the commit it claims, is now caught and named instead of silently trusted, and an honest gate's ordinary output nondeterminism is reported separately from an outcome that actually changed. A signed clean-room verification receipt chains the bundle's digest to the outcome, using the same DSSE envelope shape the result bundle and consent receipt already use (#3871).
