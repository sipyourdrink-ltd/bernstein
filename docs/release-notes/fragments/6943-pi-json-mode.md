Spawned `pi` agents now run with `--mode json`, so their runner log receives JSONL events while they work. Before, redirected stdout put pi in print mode, which writes nothing until the run ends; the log stayed 0 bytes, and heartbeat escalation killed agents that were mid-turn after about two minutes. pi decides a nonzero exit only in text mode, so it now runs under `bernstein.adapters.pi_json_launcher`, which streams every line through and exits 1 when the final assistant message stopped on `error`, `aborted` or `length`, or automatic retries were exhausted, as text mode would. The task prompt now follows `--`, so a prompt starting with `-` is no longer read as a flag.
