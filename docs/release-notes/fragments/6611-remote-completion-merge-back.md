The verdict pass now merges it through the spawner's merge path under a synthetic session named after the branch, so the merge queue, default-branch guard, blast-radius ceiling, signed file scope, quality gates, landed provenance and push all apply, then closes the task, seals its evidence, records the merge in the run journal and removes the branch.
