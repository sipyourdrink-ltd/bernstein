The dependency SBOM now emits one component per package URL: a distribution that `importlib.metadata` finds on more than one `sys.path` entry (a user-site install beside a venv, a `PYTHONPATH` overlay) no longer appears twice in `components`, which CycloneDX requires to be unique. The vendored CycloneDX, JSF and SPDX schema fixtures under `tests/fixtures/cyclonedx/` are marked byte-exact in `.gitattributes`, so a Windows checkout with `core.autocrlf` keeps the bytes their recorded digests were taken over.
