## Attribution conformance vectors added (questions 1, 2, 7, 14)

Four attribution questions — which principal initiated the run, which
agent performed each action, which identity was presented to the tool,
and which code/config/toolset actually ran — now have conformance
vectors in `tests/conformance/auditor/test_attribution_vectors.py`.

Questions 1 and 2 pass against the committed fixture: the run receipt
carries a ``principal`` field on the ``run_started`` event and an
``agent_id`` field on every action event.  Questions 7 and 14 are
registered as strict expected failures: the bundle carries no
credential or presented-identity field on ``tool_called`` events, and
no code digest, config digest, or toolset manifest in any bundle file.
The auditor conformance score moves from 3/21 to 5/21 (#5058).
