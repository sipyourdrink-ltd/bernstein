## Signed scorecard artifact binding to source journal

`src/bernstein/core/replay/scorecard_artifact.py` implements the signed, content-addressed scorecard artifact that binds a derived scorecard document to its source journal. It mirrors the signing and binding conventions of `run_receipt.py` — Ed25519/DSSE, content-addressed, offline-verifiable — with a distinct payload type (`application/vnd.bernstein.scorecard+json`) so signatures are not cross-accepted. The signed subject is the canonical JSON of a binding block containing the run id, document digest (SHA-256 of the wall-clock-excluded document body), recomputed journal head, and journal event count; the verifier rebuilds all values from the artifact bytes alone. Non-reproducible wall-clock fields (`generated_at`) are present on the document body but excluded from the hashed binding subject. The `write_scorecard_if_configured` finalization helper is wired identically to `write_run_receipt_if_configured` (#5403).
