## Agent metrics no longer leak across a metrics collector restart

`Orchestrator.__init__` already reset task metrics on every new run so a
prior run's failures could not poison this run's error budget, but the
process-wide metrics singleton kept the previous run's agent metrics.
A retrospective generated by the new run could then mix in an old run's
agents, and crash formatting the summary if one of those agents never had
its role resolved to a plain string. Agent metrics are now cleared on
restart the same way task metrics already were (#5944).
