# Tutorials

Step-by-step walkthroughs you can run end to end on your own machine. Each one
shows the exact commands, the output they printed, and what to check before
moving to the next step.

| Tutorial | You will | Needs an agent or API key |
|---|---|---|
| [Interactive quickstart](../getting-started/quickstart-tutorial.md) | Install, run a goal across agents in isolated worktrees, and read the output, cost and dashboard | yes |
| [Schedule a recurring run and verify every fire](verified-scheduled-run.md) | Register a schedule, preview its task-graph hash, let it fire, verify the fire and the audit log, and watch an edited record fail | no |
| [Sign and verify a result receipt](signed-result-receipt.md) | Sign a patch and its test log as a worker, verify it as a maintainer with key, policy and chain pinned, and watch three kinds of tampering fail | no |

For the operator problem each of these solves, see
[Use cases](../use-cases.md).
